# What live Rock records should I inspect for Groups?

For Groups, inspect these live surfaces before changing production behavior: Rock version, Security roles and permissions, DataView and report filters, Group, GroupType, Location, and Schedule records, Communication recipient, medium, and send history, Mobile shell version and mobile block settings, Registration instance and registrant records, Person, family, alias, and attribute records.
