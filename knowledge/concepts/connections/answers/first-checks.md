# What should I check first for Connections?

New-family preregistration should be connected to a clear follow-up workflow or connection process so the data captured before arrival leads to ministry action. When embedding Power BI or similar reports in Rock, pair report pages with appropriate Rock security roles and licensing checks so only authorized, licensed users can access the embedded dashboards. Before launching preregistration broadly, teams should test the full path from public form through family record creation, check-in eligibility, and staff follow-up. Family preregistration is useful when it reduces first-visit friction and improves the quality of people, family, and child data before check-in.
