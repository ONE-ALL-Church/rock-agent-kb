# What live Rock records should I inspect for Communications?

For Communications, inspect these live surfaces before changing production behavior: Rock version, Block settings, Security roles and permissions, WorkflowType and Workflow records, DataView and report filters, Group, GroupType, Location, and Schedule records, Communication recipient, medium, and send history, Mobile shell version and mobile block settings.
