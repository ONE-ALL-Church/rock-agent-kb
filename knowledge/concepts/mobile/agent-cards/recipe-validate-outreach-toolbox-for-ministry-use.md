# Recipe: Validate Outreach Toolbox for ministry use

Authorized signed-in users can see and complete intended outreach actions, and reminders arrive.

## When To Use

- Use this when the user's task matches this operational symptom or implementation path.
- Verify live Rock records before making changes.

## Live Records To Inspect

- `Device`
- `Workflow`
- `Page`
- `Block`
- `Schedule`

## Entities And Tables

- `Device`
- `Workflow`
- `Page`
- `Block`
- `Schedule`

## Steps

1. Establish the target Core and Shell versions.
2. Confirm the mobile feature and pages are installed.
3. Verify signed-in routing.
4. Review block settings and data visibility.
5. Configure or validate assignment days and reminder preferences.
6. Inspect the jobs that control reminder timing.
7. Test prayer and connection cadence records.
8. Complete a touchpoint and confirm history.
9. Test milestone or pulse behavior that is intentionally enabled.
10. Verify an actual reminder on a target device.
11. Confirm the installed Rock and Mobile Shell versions support the intended experience.
12. Verify the user is signed in.
13. Confirm page placement and access authorization.
14. Inspect the relevant block settings and contact-data permissions.
15. Check onboarding selections, assignment days and reminder preferences.
16. Verify the configured jobs and their time-of-day values.
17. Test an actual push notification on the target device.
18. Stop before treating a scheduled job run as proof of notification delivery.

- Do not treat generated guidance as live-instance proof.
