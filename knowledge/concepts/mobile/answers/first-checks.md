# What should I check first for Rock Mobile?

Start with the exact mobile shell version, page, block type, block settings, and CSS selector target. Inspect the official mobile docs, official mobile block docs, the rendered block x-ray data, theme variables, dark mode behavior, and platform-specific styling before writing selectors. For check-in or connection blocks, verify the underlying Rock configuration first because mobile UI symptoms often reflect server-side page, block, security, or data settings.
