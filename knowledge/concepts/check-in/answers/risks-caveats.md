# What risks, caveats, or source-authority limits matter for Check-In?

Large Rock releases can carry accumulated change and post-release fixes, so upgrade planning should distinguish major-version validation from routine patch-release validation and verify current release notes before action. For check-in, explicitly verify room capacity, data view filtering, schedule windows, and security before changing eligibility or room availability.
