# What live Rock records should I inspect for Content And Personalization?

For Content And Personalization, inspect these live surfaces before changing production behavior: Rock version, Block settings, Security roles and permissions, WorkflowType and Workflow records, DataView and report filters, Communication recipient, medium, and send history, Mobile shell version and mobile block settings, Person, family, alias, and attribute records.
