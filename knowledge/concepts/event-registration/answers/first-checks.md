# What should I check first for Event Registration?

Before launching preregistration broadly, teams should test the full path from public form through family record creation, check-in eligibility, and staff follow-up. New-family preregistration should be connected to a clear follow-up workflow or connection process so the data captured before arrival leads to ministry action. Family preregistration is useful when it reduces first-visit friction and improves the quality of people, family, and child data before check-in. A public preregistration page should explain the value to families and avoid creating duplicate or partial records that staff later need to clean manually.
