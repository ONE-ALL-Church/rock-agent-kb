# Generated Knowledge

This directory is the public Markdown knowledge layer generated from reviewed source records, approved claims, public contribution bundles, and model-map data.

- `concepts/` contains concept guides and agent entry points such as quickstarts, task cards, entities, release caveats, section source maps, open questions, and troubleshooting trees.
- `model-map/` contains generated public Rock model pages. References should favor the latest stable model map and call out pre-alpha differences when they matter.

Do not hand-edit generated public knowledge pages in the public repo. Update sources or reviewed contribution bundles, then rebuild the concept guides, agent pack, and public export from the build repo.

Public guidance should remain source-linked. Every page should trace back to `sources/registry.yaml`, approved claims, source citations, or reviewed contribution rows.
