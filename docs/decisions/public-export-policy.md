# Public Export Policy

The public export is the reusable community knowledge bundle. It may include
public Rock documentation, public Rock community pages, public GitHub examples,
public source-code references, approved claims, generated guides, task cards,
model-map references, and contribution templates.

Public ONE&ALL GitHub examples are allowed when they are already public, source
linked, and handled through the same license and extraction policy as other
public repositories. Their presence does not make private ONE&ALL database,
production, or local checkout details public.

The public export must not include:

- local filesystem paths;
- local-only source URIs;
- private raw media, transcripts, or normalized corpora;
- live verification evidence files;
- connected database names, logins, site IDs, or production instance details;
- generated rebuild-only metadata such as per-concept guide dependency files.

Internal review notes may mention private or live-instance details, but those
notes stay outside the public export unless rewritten into public-safe,
source-linked guidance.
